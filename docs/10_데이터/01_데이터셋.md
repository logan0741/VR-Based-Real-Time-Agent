## 1. AI-Hub 013 피트니스자세 (주 학습 데이터)

- 원본: AI-Hub 의 피트니스 자세 데이터 (받은 폴더 이름 `013.피트니스자세` 그대로 쓴다). 고정 카메라 여러 대(view1~5, 실험 로그상 5대)의 2D 키포인트 + 3D 관절 좌표 라벨.
- 쓴 부분: `1.Training/원시데이터/body_01.tar` + `1.Training/라벨링데이터/맨몸운동_Labeling.zip` 안의 `맨몸운동_01.zip`.
- 부분집합: `experiments/data_prep/prepare_fitness_subset.py` → `prepared_train_eval_body01_compact/` (만드는 법은 [00_처음_시작.md](../00_환경_준비/00_처음_시작.md) §4).

| 항목 | 값 | 출처 |
| --- | --- | --- |
| Day 폴더 | `Day05_200925_F` | `summary.json` |
| 학습 / 검증 그룹 | 1, 3 / 4 | `summary.json` |
| 그룹당 라벨 쌍 | 최대 120 (2D json 120 + 3D json 120) | `summary.json` |
| 학습 샘플 / 검증 샘플 | **17,105 / 9,010** | `pose_lifter_metrics.json` |
| 원시 추출 / 라벨 크기 | 17.868 GB / 103.5 MB | 부분집합 README |

**한 샘플**은 "한 프레임 × 그 프레임의 활성 view 하나"다 (`load_fitness_samples`). 그래서 같은 3D 타깃이 view 수만큼 반복된다.

- 입력: view 의 2D 픽셀 좌표를 이미지 크기로 나눈 `[x/W, y/H, conf]` 17×3. conf 는 관절이 라벨에 있으면 1, 없으면 0.
- 타깃: 3D 라벨의 x, y, z 를 **변환 없이** 17×3 으로 (COCO-17 순서).
- 3D 라벨 단위는 cm, **y 가 높이(위쪽 +)** 다. 2026-10-12 에 라벨 360개 파일 일부를 읽어 확인: Nose y 평균 160.3, Left Hip 91.0, Left Ankle 20.3. 그래서 MPJPE 도 cm 다.

## 2. pose_3d_v3

- `frame_81/train/*.pkl`, `frame_81/test/*.pkl` (당시 `train.pkl` 844 MB + `valid.pkl` 352 MB 도 함께 있었다 — [analysis_results.md](../40_분석_기록/analysis_results.md) §5).
- 각 pkl 은 `data_input`(2D, 17×3) 과 `data_label`(3D, T×17×3) 을 담는다.
- 폴더 구조(`pose_3d/frame_81`)가 AthletePose3D 배포 데이터의 "3D pose estimation ready data" 와 같다. 이 데이터의 출처는 AthletePose3D 로 보인다 (추정, 다운로드 기록은 남아 있지 않다).
- 쓴 곳: `python -m model_3d --check-all` 의 pose3d_direct(3D 라벨을 그대로 피드백 분석에) 와 smplx_coordinate_fit(3D 라벨 → SMPL-X 피팅), 체크포인트가 없을 때의 스모크 학습, `dataset_client.py` 30fps 재생.

## 3. pose_2d

- `annotations/{train_set,valid_set,test_set,valid_set_100}.json` (COCO 형식), `det_result/ap2d_*_det.json`, 이미지 폴더.
- `ap2d` 라는 파일 이름과 폴더 구조가 AthletePose3D 의 "2D pose estimation ready data" 와 같다 (추정).
- 쓴 곳: MediaPipe / MoveNet Lightning / Thunder 비교 → [02_2D_포즈추정기_비교.md](02_2D_포즈추정기_비교.md).

## 4. AthletePose3D

- https://github.com/calvinyeungck/AthletePose3D — 운동선수 동작 3D 포즈 데이터셋. 비상업·연구 목적 라이선스 동의 후 다운로드.
- 루트에 저장소를 clone 해 두었지만 이 브랜치 코드는 `AthletePose3D/` 를 import 하거나 읽지 않는다. 데이터 조사 단계에서 Fit3D, MM-Fit 등과 함께 검토했다 ([CHANGELOG.md](../40_분석_기록/CHANGELOG.md) 2026-03).

## 5. 저장소 안의 작은 샘플 (`data_samples/`)

| 파일 | 내용 | 쓰는 곳 |
| --- | --- | --- |
| `sample_keypoints.json` | `{frame_id, payload}` 1프레임 | `run_pipeline.py --input` 예시 (`model_3d/sample_keypoints.json` 도 있음) |
| `squat_left_1_keypoints.json` | `[{frame, keypoints}]` 267프레임 스쿼트 | `/api/expert`(뷰어 전문가 패널), `tools/play_squat.py`, `run_steps.py --step 1` |
