# 판정 변형 기록

루트의 [versions/](../../versions/README.md) 폴더는 판정 규칙을 바꿔 본 세 번의 시도를 적은 **기록**이다. 코드가 아니고, 채택된 동작은 `final/` 에 들어 있다.

| 변형 | 한 줄 | 지금 |
|---|---|---|
| `camera_quality_feedback_v1` | 몸이 화면에 다 안 잡힌 프레임은 점수·횟수에서 뺀다 (`countable=false`) | 채택. 기준은 `0.25/0.02` → `0.12/0.01` 로 완화 |
| `scoring_normalization_lenient_v1` | 점수 변환·피드백 threshold 를 느슨하게 | 채택 안 함 (기준 원복) |
| `feedback_hold_mirror_v1` | 기준은 그대로 두고 같은 경고가 프레임마다 쌓이는 것을 hold 로 막음, `feedback_event`, 좌우 반전 버튼 | 채택 |

교훈은 하나다. "판정이 빡빡하다·경고가 너무 많다" 는 불만을 **평가 기준을 낮춰서** 풀지 않고, **입력 품질(카메라 게이트)과 표시 정책(hold)** 을 분리해서 풀었다. 기준을 낮추면 평가 자체가 약해지기 때문이다(`feedback_hold_mirror_v1` 의 변경 이유).

lenient 문서가 "다음 후보" 로 적어 둔 회전 정규화, 좌/우 측면 자동 판정, 초반 1~2 초 캘리브레이션은 **구현되지 않았다.**
