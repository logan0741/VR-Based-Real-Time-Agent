# 처음 시작 — 아무것도 없는 Windows PC 에서

목표: 이 문서 끝에서 `http://127.0.0.1:8000/api/health` 가 `{"status":"ok", …}` 를 돌려준다. 모든 명령은 PowerShell 에서 친다.

## 1. 깔아 둘 것

| 도구 | 버전 | 왜 |
|---|---|---|
| Git | 아무 최신 | 저장소 받기 |
| Python | **3.8** (작성자 3.8.10) | 서버. 코드가 3.8 기준으로 맞춰져 있다(전처리·TTS 모듈 상단의 `from __future__ import annotations`) |
| Node.js | **22** (작성자 v22.20.0, npm 10.9.3) | Quest 앱 빌드(Vite 5 + TypeScript 5) |
| MySQL | 선택 | 세션 요약 저장. 없어도 앱은 끝까지 돈다 |
| cloudflared | 선택 | 폰·Quest 를 HTTPS 도메인으로 붙일 때 → [01_도메인_터널.md](01_도메인_터널.md) |

Python 은 python.org 설치본의 `py` 런처를 쓰면 여러 버전이 있어도 `py -3.8` 로 고를 수 있다.

## 2. 받기와 가상환경

```powershell
git clone -b App https://github.com/logan0741/VR-Based-Real-Time-Agent.git
cd VR-Based-Real-Time-Agent

py -3.8 -m venv .venv
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
python --version          # Python 3.8.x 가 나와야 한다
```

`final/scripts/*.ps1` 은 가상환경 경로를 따로 지정하지 않고 그냥 `python` 을 부른다. 그래서 스크립트를 돌리는 창에서는 **항상 먼저 `Activate.ps1`** 을 한다.

## 3. `.env`

```powershell
Copy-Item .env.example .env
```

- 서버는 시작할 때 루트의 `.env` 를 읽는다(`server.py` 의 `load_env_file`). 셸에 같은 이름이 이미 있으면 셸 값이 이긴다.
- 기본값 `DB_ENABLED=false` 로 두면 MySQL 없이 돈다.
- MySQL 을 쓸 거면 `DB_ENABLED=true` 와 `DB_HOST`·`DB_PORT`·`DB_USER`·`DB_PASSWORD`·`DB_NAME`(기본 `vr_fitness`) 을 채운다. 서버가 처음 연결할 때 DB 와 `exercise_sessions` 테이블을 스스로 만든다(`CREATE DATABASE/TABLE IF NOT EXISTS`).
- `CAMERA_MIN_CONFIDENCE`·`CAMERA_EDGE_MARGIN` 만은 `.env` 보다 먼저 import 시점에 읽혀서 `.env` 로는 바뀌지 않는다. 바꾸려면 셸에서 `$env:CAMERA_MIN_CONFIDENCE="0.2"` 처럼 설정한다.

## 4. 설치·검증·빌드 한 번에

```powershell
.\final\scripts\00_pipeline.ps1 -Install -NoServer
```

이 한 줄이 하는 일:

1. `01_install.ps1` — `python -m pip install -r final\requirements.txt`, `npm --prefix final install`
2. `05_verify.ps1` — `python -m py_compile` (server.py, latency_lab 두 파일) → `npm --prefix final run build` (`tsc && vite build`, 결과는 `final\app_dist`)
3. `-NoServer` 라서 서버는 띄우지 않고 `NoServer was set, so the server was not started.` 로 끝난다.

`final/requirements.txt` 에는 `torch`, `tensorflow`, `mediapipe`, `smplx` 같은 큰 패키지가 들어 있어 첫 설치가 오래 걸린다. 실시간 2D 경로만 보면 `server.py` 가 import 하는 `torch`, `fastapi`, `uvicorn`, `numpy`, `opencv-python`(전문가 캐시 모듈이 `cv2` 를 import), `dtaidistance`, `pyttsx3`, `pymysql`, `websockets` 가 실제로 필요하다. 나머지(`tensorflow`, `mediapipe`, `smplx` 등)는 이전 3D·오프라인 추출 경로용인데, 목록을 줄여서 설치해 보는 검증은 하지 않았다.

### 설치 확인

```powershell
python -c "import dtaidistance, fastapi, torch, cv2, pyttsx3; print('ok')"
```

`dtaidistance` 가 실패하면 `pip install dtaidistance==2.3.12` 를 따로 친다(최신 버전은 빌드가 깨진 적이 있다 → [트러블슈팅 2](../10_실행/01_트러블슈팅.md)).
