# 처음 시작 — 환경, 모델 파일, 데이터셋, 스모크 테스트

이 문서는 빈 PC 에서 Pose3D 브랜치를 학습·분석 가능한 상태로 만드는 순서다. 모든 명령은 저장소 루트에서 실행한다.

## 1. 파이썬 환경

`environment.yml` 은 conda 환경 `vr-real-time-agent` 를 **Python 3.10** 으로 만들고 `requirements.txt` 를 pip 로 설치한다.

```powershell
conda env create -f environment.yml
conda activate vr-real-time-agent
```

`requirements.txt` 에 들어 있는 것:

- 데이터·시각화: numpy, pandas, scipy, scikit-learn, matplotlib, tqdm, opencv-python
- 포즈 추정: mediapipe
- 3D 스택: smplx, fastapi, uvicorn, websockets, pymysql, Pillow (브랜치를 정리하면서 코드가 실제로 import 하는 것을 추가했다)
- 당시 앱 설정용: python-dotenv, openai, pyttsx3, dtw-python — 이 브랜치 코드는 쓰지 않는다

**PyTorch 는 목록에 없다.** CUDA 빌드가 PC 마다 달라 따로 설치한다.

```powershell
pip install torch --index-url https://download.pytorch.org/whl/cu121   # CUDA 12.1 예시
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
```

`experiments/hpe_comparison/` 의 MoveNet 비교는 tensorflow-cpu / tensorflow-hub 가 더 필요하다 (`experiments/hpe_comparison/requirements.txt`).

## 2. 점검

```powershell
python run_steps.py --check
powershell -ExecutionPolicy Bypass -File .\scripts\check_fitness_training_env.ps1
```

`run_steps.py --check` 는 필수 패키지(torch, fastapi, uvicorn, numpy, mediapipe, cv2, websockets, matplotlib)와 선택 자원(SMPL-X 모델, pose_3d_v3, 013 데이터셋, 리프터 체크포인트)을 표로 보여 준다. `check_fitness_training_env.ps1` 은 torch/CUDA, 데이터셋 경로, train/val 샘플 수(정상: 17105 / 9010)를 찍는다.

## 3. SMPL-X 모델 파일 (SMPL-X 경로를 쓸 때만)

SMPL-X 는 막스플랑크 연구소 라이선스 모델이라 **이 저장소에 넣지 않고 재배포하지 않는다** (`.gitignore`: `/smplx_locked_head/`, `models_smplx_v1_1.zip`, `*.npz`, `*.pkl`, `*.fbx`).

1. https://smpl-x.is.tue.mpg.de 에 가입하고 라이선스에 동의한 뒤 `models_smplx_v1_1.zip` 을 받는다.
2. 압축을 풀어 중립 모델을 다음 위치에 둔다.

```text
<저장소 루트>/
  smplx_locked_head/
    neutral/
      model.npz        ← 이 파일을 코드가 찾는다
```

- `fitter.py resolve_smplx_model_path()` 는 `SMPLX_MODEL_PATH` → `SMPLX_NEUTRAL.npz`, `models/SMPLX_NEUTRAL.npz`, `models/smplx/…`, `smplx_locked_head/neutral/model.npz` 순으로 찾는다. 다른 곳에 두면 `SMPLX_MODEL_PATH` 로 지정한다.
- `.pkl` 을 가리켜도 옆의 `model.npz` 를 먼저 쓴다. `.pkl` 은 Python 3.10 에서 `chumpy` 를 요구할 수 있다 (`SMPLX_ALLOW_PKL=true` 로 강제).
- 처음 실행 때 손 PCA·얼굴 랜드마크 호환 캐시를 `model_3d/artifacts/smplx_cache/` 에 만든다 (gitignore).
- "smplx_locked_head" 라는 폴더 이름은 당시 로컬에서 쓰던 이름이다. 공식 zip 안의 폴더 구조와 이름이 다를 수 있으니 `model.npz` 위치만 맞추면 된다 (공식 zip 내부 구조는 이 정리에서 확인하지 않았다).

이 파일이 없으면 `--check-all` 의 `smplx_coordinate_fit` 이 `unavailable` 로 나오고 나머지는 그대로 돈다.

## 4. 데이터셋 배치 (학습할 때만)

AI-Hub 의 **"013.피트니스자세"** 를 받아 루트에 둔다. AI-Hub 약관상 재배포하지 않는다.

```text
<저장소 루트>/
  013.피트니스자세/
    1.Training/
      원시데이터/body_01.tar                 ← 원시 이미지 tar
      라벨링데이터/맨몸운동_Labeling.zip      ← 2D/3D 라벨 (안쪽에 맨몸운동_01.zip)
    prepared_train_eval_body01_compact/      ← 아래 스크립트가 만든다
```

```powershell
python experiments/data_prep/prepare_fitness_subset.py
# 옵션: --dataset-root, --raw-archive body_01.tar, --target-raw-gb 20, --min-groups 3, --val-groups 1, --output-name prepared_train_eval_body01_compact
```

스크립트는 루트에서 `013.` 으로 시작하는 폴더를 찾고, 이름에 `Training` 이 들어간 하위 폴더에서 tar 가 있는 폴더(원시)와 zip 이 있는 폴더(라벨)를 고른다. 당시 결과(`prepared_train_eval_body01_compact/summary.json`, README):

- Day 폴더 `Day05_200925_F`, 학습 그룹 1·3, 검증 그룹 4, 그룹당 라벨 최대 120쌍
- 원시 추출 17.868 GB, 라벨 103.5 MB
- 학습 샘플 17,105 / 검증 9,010 (프레임 × 활성 view)

다른 데이터셋(pose_3d_v3, pose_2d)은 [10_데이터/01_데이터셋.md](../10_데이터/01_데이터셋.md).

## 6. 스모크 테스트

```powershell
python -m model_3d --dummy --frame-id smoke-test     # torch 만 있으면 된다
python -m model_3d --check-all --output model_3d\artifacts\my_check.json
```

- `--check-all` 은 네 검사(dummy / pose3d_direct / smplx_coordinate_fit / lifter_checkpoint)를 돌린다. 자원이 없는 검사는 `skipped`/`unavailable` 로 적고 넘어간다.
- 체크포인트가 하나도 없고 `pose_3d_v3` 가 있으면 작은 스모크 체크포인트를 먼저 학습한다.
- `--output` 없이 인자 없는 `python -m model_3d` 는 커밋된 `model_3d/artifacts/model_3d_check_all.json` 을 덮어쓰니 주의한다.

2026-10-12 정리 때 실제 결과 (Python 3.8.10, torch 2.0.1+cpu, 체크포인트는 원래 작업 폴더의 `fitness_pose_lifter_latest_best.pt` 를 `--lifter-checkpoint` 로 지정):

```text
dummy                 ok           116.2°  Good
pose3d_direct         skipped      pose_3d_v3 directory not found.
smplx_coordinate_fit  unavailable  SMPL-X model file not found
lifter_checkpoint     ok           166.7°  Lower your hips
```
